# JarvisMK
Jarvis is a free voice assistant for Windows, inspired by the one from Iron Man. He controls your PC for you and connects to the apps you use. His memory learns your taste, what you tell him and what he picks up on his own, so he gets better the more you use him. Highly customizable, with weekly updates.

Pretty new so bugs are more common, to report one either use the discord https://discord.gg/sNvfPDhgqj or use the in app report a bug feature
